# Derived data

These files are redistributable summaries of the frozen SAREF experiment.

- `condition_level_results.csv`: task success, state validity, recovery success, and mean cost by failure class and recovery strategy.
- `fixed_strategy_summary.csv`: aggregate success, cost, regret, and oracle selections for the three fixed recovery strategies.
- `propagation_summary.csv`: propagation radius, affected nodes, invalid writes, and amplification by condition.
- `action_set_ablation.csv`: coverage and oracle mean cost under restricted recovery action sets.
- `leave_one_failure_class_out.csv`: leave-one-failure-class-out sensitivity analysis.

These files are derived summaries and do not redistribute upstream InterCode benchmark assets.
